# Parking Lot Manager

A C++ console application for managing a parking lot.

## Features

- Register vehicles
- Remove vehicles
- Search vehicles by plate number
- Display parked vehicles
- Calculate parking fees
- Input validation and exception handling

## Technologies

- C++
- Object-Oriented Programming
- STL vectors
- Exception handling

## Purpose

This project was created to practice C++ fundamentals, object-oriented programming, input validation, and basic data management.
